- 등록: 2026-11-02
- 시나리오 행렬 파일: `experiments/matrix.json`
- 실행: `scripts/experiment.py`

## 1. 무엇을 주장하려는가

"출발 시각과 도착 기한이 같을 때, 매일 새 예보로 경로와 속력을 다시 정하는 계획이 최단 경로를 일정 속력으로 가는 것보다 연료를 X% 덜 쓴다." X는 항로·계절별 평균과 95% 신뢰구간으로 냅니다. 효과가 0과 구별되지 않으면 그대로 보고합니다.

KCS는 실제로 건조된 배가 아니므로 X는 같은 연료 모델 안에서의 상대 절감입니다. 절대 연료(t)는 추정값입니다.

항로 6 × 계절 2 × 출발 10 = 120개 항해입니다. 가장 긴 항해(732시간)도 각 계절 예보 자료 안에서 끝납니다.

## 3. 비교하는 계획

| 이름 | 내용 | 언제 추가 |
|---|---|---|
| 최단 기준선 | 출발 때 계획한 최단 경로를, 그 예보로 기한에 맞춘 일정 속력으로 감 | WP0 |
| 한 번 계획 (once) | 출발 때 한 번 경로와 속력을 정하고 그대로 감 | WP0 |
| 매일 재계획 (daily) | 24시간마다 그때 나와 있는 가장 새 예보로 남은 길을 다시 계획 | WP0 |
| 오라클 | 실제 날씨를 예보 대신 주고 세운 계획. 절감의 상한 | WP2 |

- 예보는 시작 8시간 뒤에 나온다고 봅니다.
- 엔진이 계획 속력을 낼 수 없는 구간은 낼 수 있는 가장 빠른 속력으로 갑니다.
- 모든 계획은 같은 평가기(`route/evaluate.py`)로 연료와 도착 시각을 계산합니다.

## 4. 평가 날씨

계획에 쓴 날씨와 평가에 쓴 날씨를 나눕니다. 모든 결과 표에 평가 날씨를 적습니다.

| 단계 | 평가 날씨 | 성격 |
|---|---|---|
| WP0 | 매일 ECMWF 예보의 0~21시간을 이은 것 | 계획과 같은 예보 체계. v25와 비교용 |
| WP1부터 (주 결과) | ERA5 바람·파랑 + Copernicus Marine 해류 | 계획에 쓰지 않은 독립 자료 |

## 5. 지표

- 연료(t), 최단 기준선 대비 절감률(%), 도착 지연(시간), 기한 위반 횟수
- 포착률 = (기준선 연료 − 계획 연료) / (기준선 연료 − 오라클 연료) (WP2부터)
- 절감 분해: 경로 몫(최적 경로 + 일정 속력)과 속력 몫(최단 경로 + 최적 속력) (WP5)

## 6. 통계

- 같은 항로·출발일끼리 짝지어 비교합니다.
- 항로·계절마다 평균 절감률과 부트스트랩 95% 신뢰구간(10,000번 재표집)을 냅니다.
- Wilcoxon 부호 순위 검정(양측, 유의수준 0.05)으로 절감이 0과 다른지 봅니다.
- 출발일을 골라 빼지 않습니다. 계산이 실패한 항해도 실패로 기록합니다.

## 7. 합격 기준 (2026-11-02 확정)

| 작업 | 기준 |
|---|---|
| WP0 평가기 | 같은 입력을 두 번 돌리면 같은 결과. 저장된 v25 항적을 새 평가기로 같은 날씨에서 다시 계산하면 연료 차이 ±0.1% 이내 |
| WP1 실제 날씨 | 관측 대비 오차 표를 냄. v25 절감률이 ERA5 평가에서도 같은 부호인지 보고 (합격선 없음, 보고 의무) |
| WP2 최적화 | 제르멜로 해석해 대비 최소 시간 오차 ≤1%, 쌍대 간극 중앙값 ≤0.5%, 오라클 조건에서 최단 기준선보다 나쁜 계획 0건 |
| WP3 연료 모델 | 정수 저항·자항 ±3%, 정면파 부가저항 피크 ±15%, 몬테카를로 표본의 90% 이상에서 절감률 부호 유지 |
| WP4 외부 비교 | 공개 거리표(NGA Pub. 151) ±3%, 독립 구현 경로보다 0.5% 넘게 나쁘면 원인 규명 |
| WP5 본 실험 | 모든 항로·계절에 신뢰구간 보고 |
